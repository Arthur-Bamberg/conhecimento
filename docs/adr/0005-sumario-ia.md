# Sumário é gerado pela IA

A lista precisa de recortes curtos, mas o `corpo` é markdown da pessoa para o chat. Um campo de descrição editável (ou o primeiro parágrafo do corpo) mistura duas funções. O **Sumário** do Texto e o **Sumário do workspace** são colunas próprias, preenchidas pelo provider no create/patch/delete; a UI não deixa editar. O módulo de IA continua lazy: o primeiro save de Texto ou a primeira mensagem de chat carrega o provider.
