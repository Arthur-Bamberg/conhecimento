# Textos — overrides

Lista + criação na mesma coluna. Sumário do workspace acima do formulário (só leitura, gerado pela IA).

- Empty state aponta para o formulário «Novo texto», não para uma rota extra.
- Apagar na lista: `window.confirm` (já coberto pelo e2e).
- Cards da lista: o link ocupa a área principal; o ícone de lixeira tem `aria-label` e alvo ≥44px.
